# 🚲 GesBike Taller - Sistema de Gestió de Taller, Estoc i Preus

Projecte Intermodular - 2n DAM (Curs 2026-2027)
**Autor:** Ainhoa Mortes Martinez

---

## 📋 Descripció del Projecte
**GesBike Taller** és una aplicació d'escriptori client-servidor dissenyada per a digitalitzar la gestió diària de tendes i tallers de reparació de bicicletes. 

El projecte naix d'una necessitat real detectada en un comerç i taller físic familiar: els programes de facturació genèrics actuals resulten rígids i no ofereixen eines específiques per al seguiment tècnic del taller ni per a l'optimització de compres. GesBike resol aquest problema centralitzant l'historial mecànic, les cites, l'inventari i la comparació de proveïdors en una única eina àgil.

## 🚀 Funcionalitats Principals
1. **Historial Clínic de Bicicletes i Clients:** Registre de cada client, les seues bicicletes i l'historial complet de reparacions, manteniments i modificacions realitzades.
2. **Calendari i Gestió de Cites:** Agenda visual per a planificar les entrades al taller i controlar l'estat de cada reparació en temps real.
3. **Control d'Estoc i Vendes de Mostrador:** Gestió d'inventari de recanvis i accessoris d'unitats vendudes com per peces utilitzades al taller.
4. **Comparador de Proveïdors i Recomanador de PVP:** Eina d'anàlisi que compara els catàlegs dels proveïdors habituals per indicar on comprar cada recanvi al millor preu i calcular automàticament el preu de venda recomanat segons el marge comercial desitjat.

## 🌱 Contribució als ODS (Sostenibilitat)
* **ODS 11 (Ciutats i comunitats sostenibles):** Foment de la mobilitat sostenible facilitant el manteniment professional del parc ciclista local.
* **ODS 12 (Producció i consum responsables):** Impuls a l'economia circular i la reparabilitat, allargant la vida útil de les bicicletes i components en lloc de substituir-los.

## 📂 Estructura del Repositori
El repositori s'organitza seguint l'arquitectura client-servidor del sistema:

* `/client-desktop`: Codi font de l'aplicació d'escriptori per al taller i mostrador.
* `/server-api`: Servidor backend i API REST per a la lògica de negoci i concurrència.
* `/database`: Diagrames Entitat-Relació, model relacional i scripts SQL de la base de dades central.
* `/docs`: Documentació de les fases del projecte i wireframes de les pantalles principals.
